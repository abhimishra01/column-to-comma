# Code review: regression lens (Sherlock)

Verdict: forward mode (column to list) is correct on every case I recomputed and the template rules hold; reverse mode (list to column) has two real bugs (spurious blank item, line breaks ignored for an explicit separator) and the JSON quick setting can output invalid JSON. Must-fix: 0. Should-fix: 5.

Method: `npm test` (39 pass); about 45 hand-checked cases run against `src/lib/convert.js`; the built site driven in a real browser (presets, mode switch, reload persistence, Custom separator, Ctrl+Enter with the clipboard); `dist/` checked for template rules.

Verified OK: canonical on all pages (404 canonical is /404/ with noindex, fine); `public/_headers` has both pages.dev noindex rules; privacy, terms, about, contact in sitemap; 404 built; robots.txt and sitemap-index present; `ads.txt` is a comment only and no GA or AdSense script when the IDs are empty; the article's worked example gives `(1001, 1002, 1004)`; FAQ claims (apostrophe doubling, `007` stays quoted, Oracle 1,000 limit) match the code; option save and restore works; Ctrl+Enter copies and the stats line confirms; Custom `\n` works. Speed: 100k lines with sort, dedupe and quotes took 191 ms; reverse of 200k quoted items took 162 ms; 1M lines took 1.3 s (debounce applies above 200k characters). The "well under a second" claim holds for 100k.

Known template leftovers (on the fixer's list): README, scripts/new-tool.sh, tracked screenshots, duplicate legal links, build-date "Last updated", British spelling.
