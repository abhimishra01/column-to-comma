# Code review, maintainer lens: column-to-comma

Verdict: solid, fast core (39 tests pass, 100k lines in about 130 ms, no HTML injection paths, all output via textContent/value); ship after fixing 1 must (JSON preset can emit invalid JSON) and the should rows below. Must-fix count: 1.

Checked by running the code: `npm test` (39 ok) plus a probe script (outside the site folder) for the edge cases below. Known template leftovers (README, new-tool.sh, tracked screenshots, duplicate legal links, build-date "Last updated", British spelling) are on the fixer's list and not repeated here.
